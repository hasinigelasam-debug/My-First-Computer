🖥️ Lesson 1: Monitor

What is a Monitor?

A monitor is the screen of the computer. It displays text, pictures, videos and games.

Uses

  • Shows text
  • Shows pictures
  • Shows videos
  • Helps us watch online classes

⌨️ Lesson 2: Keyboard

What is a Keyboard?

A keyboard is used to type letters, numbers and symbols.

Uses

  • Type names
  • Write homework
  • Type numbers

🖱️ Lesson 3: Mouse

A mouse is used to move the pointer and click on icons.

Uses

  • Open files
  • Play games
  • Draw pictures

💻 Lesson 4: CPU

The CPU is called the brain of the computer. It controls all the work of the computer.

🖨️ Lesson 5: Printer

A printer prints documents and pictures on paper.
